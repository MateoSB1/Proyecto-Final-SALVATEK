# 🌐Proyecto de JavaScript de CoderHouse: SALVATEK Electronics🌟

Es una aplicación web desarrollada en JavaScript que permite a los usuarios navegar y comprar productos electrónicos de la tienda **SALVATEK Electronics**. La plataforma incluye una interfaz interactiva donde los usuarios pueden agregar productos a un carrito de compras, gestionar cantidades y finalizar compras de manera intuitiva.

## ⚙️Características Principales
- Carga dinámica de productos desde un archivo JSON.
- Gestión de carrito de compras con almacenamiento en `localStorage`.
- Interfaz responsiva utilizando **Flexbox** y **CSS Grid**.
- Diseño modular con **SASS (SCSS)** y uso de variables, mixins y extends.
- Notificaciones de acciones con **ToastifyJS**.
- Manejo de eventos y validaciones en el formulario de compra.

## 🛠️Tecnologías Utilizadas
- **HTML5**: Estructura semántica del sitio.
- **CSS3 / SCSS**: Estilización y diseño responsivo.
- **JavaScript (ES6+)**: Funcionalidad interactiva.
- **ToastifyJS**: Notificaciones emergentes.

## 🚀Archivos Principales

- **index.html**: Contiene la estructura HTML de la página principal.
- **styles.css**: Estilos CSS compilados a partir de los archivos SCSS.
- **script.js**: Lógica principal de JavaScript para manejar la interacción del usuario, el carrito de compras y la finalización de la compra.
- **productos.json**: Archivo JSON que contiene la lista de productos disponibles.
- **scss/**: Carpeta que contiene los archivos SCSS para la organización modular de estilos.
